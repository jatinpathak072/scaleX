# ScaleX Blog Landing Page

A modern and visually appealing blog landing page built using **HTML5** and **CSS3**. The project features a dark-themed user interface with category filters and blog cards designed for a clean reading experience.

## 🚀 Features

* Modern dark-themed design
* Clean and minimal user interface
* Blog category filters
* Stylish blog cards
* Pure HTML and CSS implementation
* Easy-to-understand code structure

## 🛠️ Technologies Used

* HTML5
* CSS3
